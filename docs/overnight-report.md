## 2. 재현·확장 (한 줄 명령)

```
python scripts/build_long.py --clip <루프.mp4> --pools <곡 폴더...> --duration 7200 --out <파일.mp4> --ambience <베드.flac> --listen-pack [--theme <테마>]
```

2시간 렌더: 전환 평가가 캐시돼 있으면 약 5분. 새 테마: `config/themes.json`에 항목 추가 → `python scripts/theme_pipeline.py <테마>`.

## 4. GPT 토의로 잡은 실제 문제

- 사이버펑크 설명란에 서울 레트로 문구가 들어가 있었음 → 테마별 설명·태그
- 배경음이 5초짜리 반복 → 2분 베드 생성
- 영상 모델이 '할매분식'을 '할매분삭'으로 바꿈 → 간판 프레임 고정 + 의도 글자 대조 판독
- 디스토피아 마지막이 큰 소리 상태에서 3초 만에 끊김 → 12초 페이드
- 글자 없는 장면이 일본 골목처럼 읽힘 → 공중전화 부스 등 한국 소품 편집

## 5. 시도했지만 채택하지 않은 것

- Z-Image 덧칠로 간판 자연스럽게 하기: 강도 0.45 넘으면 글자 다시 깨짐
- 창문 소품 교체(v5): 점수 변화 없음
- 최종 -16 LUFS(GPT 제안): YouTube는 큰 소리만 낮추므로 -14 유지. `--target -16`으로 바로 전환 가능
- 키·BPM(Camelot) 재편성, 밝기 레이어 루프: 데이터 부족/효과 작음으로 보류
- 전환 '자동 판정': 곡 자체 강약과 실수를 구분 못 함 → 청취 팩으로 대체
